# jogo-da-forca-em-C
 Jogo da Forca desenvolvido em C para a disciplina de Algoritmos e Programação 1 – UNIVALI. O jogo utiliza a palavra "WHILE" como desafio, permitindo ao jogador tentar letras, registrando acertos, erros e letras já utilizadas, além de exibir visualmente a forca conforme os erros aumentam.
